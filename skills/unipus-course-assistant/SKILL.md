# UMOOCs 课程助手

将网页检查、真实视频播放、作答和结果核验连接成可续接流程。先读当前用户指令和任务记录，沿用已有授权；技能包本身不授予登录、开始考试或提交权限。

首次安装、其他账号或需要尽量无人值守时，读 [references/startup.md](references/startup.md)。确认登录与范围后持续处理已授权任务，用户没有设定逐项确认门槛时不要重复询问；只有明确人工阻塞才暂停。

## 启动与账号

- 使用当前环境已有的浏览器工具、连接器或可用的 Playwright。遵守宿主浏览器工具的访问范围；缺少 DOM/脚本权限时使用该工具提供的 UI 方法。不要把本包的工具代码当作绕过宿主权限的途径。
- 用户亲自登录及完成验证码。不同账号使用独立浏览器配置；重新核对登录账号、课程链接和选课状态。授权只适用于当前用户指定账号与范围。
- 在用户指定目录保留运行文件。续接时先读精简记录和实时状态，不重新扫描整站。保留一个浏览器进程，通过命令或连接复用会话，避免每题重启浏览器。

## 目录与规则

提取任务 ID、链接、标题、类型、状态，区分视频、可重复作业、单次或次数未知的测验/考试。不要只凭“作业”标题推断可重复。读取说明页上的机会次数、计时、自动提交及完成条件；“开始考试”可能消耗机会或启动计时，检查前不要点击。

用户明确授权单次考试后可以继续，无须逐份重复索取授权。单元测验与期末考采用相同的一次提交流程，范围不明确时一次问清。未知规则先查明；不能查明且用户未授权消耗未知机会时跳过并汇总。已提交项目不重新尝试；按用户要求决定是否读取历史结果。

相互独立的说明页可批量只读提取，但不能批量开始考试。按实际作答项计数：一个材料题可能展开成多个小题。记录倒计时是否实际出现，不能把“未显示”写成“没有限时”。

## 按单元分工

首次启动默认展示勾选面板，而不是让用户编写分工文本。登录并确认账号/课程后、开始任何任务前，读取并按宿主允许的脚本写入方式执行 scripts/task-picker.js 的函数表达式，参数为 {courseId,courseName,scope?}。scope 只预填同账号已有明确分工；新账号不预选作业、测验或期末考。不要替用户点击确认。用户确认后以 {action:'read'} 读取 status:'confirmed' 的 scope，写入本地 task-scope.json；pending 时继续等待，不能猜测选择。支持分别勾选15个单元作业/测验，独立期末考、视频及通知恢复选项。视频与通知恢复默认勾选、可取消；用户确认前不据默认值执行修复。video.enabled 为 false 时不启动视频脚本。用户要求更改范围时以 {action:'reset',courseId,scope:当前分工} 重开；已开始的单次测试无法撤销。分工确认本身不替代未取得的开始/提交授权。不能注入页面时可展示 assets/task-picker.html；无法读取用户勾选结果时再用一次自然语言确认，不假称所有宿主都支持自动读取。

依据用户的明确选择建立本地task-scope.json：普通作业homework与单元测验unitQuiz分别记录AI负责的单元数组，期末测验finalExam独立为ai/manual。未明确选择的项目默认manual。可从assets/task-scope.example.json建立；scripts/task-scope.js校验范围并给出每项decision。用户用自然语言指定U1–U5、U8或全部时由智能体展开，不能让用户逐项改JSON。账号或课程改变重新确认分工，文件本身不是授权证据。

每次进入、开始或提交作业/测验前检查实时分工，只有decision为ai且用户已授权开始/提交才操作。manual项目不进入答题页面，保留目录状态供汇总。未识别单元/类型或错误范围停止该项；不凭顺序猜测期末考属于某单元。用户可更改未开始任务范围，遇到活动中的计时测试说明已开始状态，不假称可撤销机会。续接沿用同账号已明确授权；用户更改优先于配置文件。

## 视频控制

只在授权课程的已核对视频页操作，排除作业和考试。发现 iframe 层级、真实 video 元素、播放器支持的速度、自然结束事件和服务器完成标记。优先使用平台已有倍速；用户授权脚本调速时，仅改变真实播放器速度，不调用或伪造学习记录，不跳过服务器要求。

优先静音播放并用播放器原生菜单选择可用的最低清晰度，以减少打扰和网络占用；核验实际静音与清晰度。提供可见的倍速选择及暂停串播按钮，明确串播暂停与媒体暂停的区别。用户明确授权跳转实验时，先抽查真实video.currentTime跳到末尾三秒、自然结束及服务器目录记录；不能由倍速成功推断跳转成功，也不能称跳转为完整观看。本课程1.4.1提供“末尾三秒/完整播放”选择，前者已在测试账号多节验证；其他课程重新核验规则与结果后再启用。

速度验证分两步：实际时间是否按设定倍率前进，以及自然播完后课程目录是否记录完成。第二步通过后才启用下一课。更高倍速与并发播放各自需要验证，不能由 4× 成功推断。跨域帧握手校验 origin、source 和任务 ID。

让脚本负责播放、结束后确认、跳过已完成、下一视频、页面恢复和异常提示。倍速未获确认时可实际原速重播；原速仍不确认就停留提示。不要无限重试弹题、自动点击身份验证或绕过播放限制。稳定运行后停止模型持续轮询；用浏览器内计时器和状态栏承担监测。

本课程1.4.1默认顺序：末尾三秒 → 跳转失败或目录未确认则16×从头完整播放 → 仍未确认则1×从头重播 → 提示停止。每次自然结束最多轮询目录120秒；跳转只作用于真实媒体位置，不能伪造记录。优先静音和最低可用画质，保留方式/倍速选择框及醒目的暂停串播按钮。详见README最新实现逻辑与validation记录。

处理《英语语法与写作》（课程 ID：8021）时可参考 [assets/unipus-8021-video.user.js](assets/unipus-8021-video.user.js)。新课程先读 [references/unipus-adapter.md](references/unipus-adapter.md)，重新生成任务白名单和匹配范围。

## 解答、填入、提交

1. 每次只开始一份有计时或单次机会的试卷。提取一次完整的题干、材料、选项、字段身份和规则；图片、音频、下划线等语义依赖应使用原页面，不用纯文本替代。
2. 首轮直接解答；第二轮重新按题干验证语法、逻辑、时态、选项和填写格式，集中复查分歧。同一模型两轮检查存在相关错误，不能称为两个独立评审。必要且获授权时才增加另一评审。
   普通作业采用解答、填写读回、提交核验及批阅反馈重试的常规流程；填空优先保留给定原词，检查格式和空格边界。记录首次正确数与重试后的最终结果，不宣称增加复核一定提高首次正确率。单次测验仍保留完整的提交前复核。
3. 题干有错字或答案可能有多种表达时，结合给定词库、上下文及用户已有已批阅练习作定向核对；不要获取未公开答案、探测判分接口或套用其他账号结果。判分格式与语言本身正确性可能不同，保留未解决歧义。
   判断题需区分句子结构、用词/拼写和上下文一致性；有歧义时分别检查，不能未经证据就把所有瑕疵都当成平台要求的错误。多分句的单空题核对所问范围，不把多个主语拼进一个答案。可重复作业按自身批阅反馈修正，不能把另一账号的答案作为首次正确率保证。
4. 填入前校验当前试卷身份、题目 ID、字段类型和数量。按稳定 ID 映射，避免按错误的题干编号或易变化的第 n 个元素定位。可用 [scripts/assessment-dom.js](scripts/assessment-dom.js) 在宿主允许 DOM 操作的浏览器工具中提取、填入、读回；它不提交试卷。
5. 读回真实选中值和文本，核对每题对应关系、英文标点、空格、大小写及遗漏。题量较大的试卷在这一步完整复核，不能以“程序写入成功”代替。
6. 按授权点击正常提交及确认按钮。单次考试只提交一次；提交后网络超时先查当前状态和结果页，避免再次提交。页面出现次数用尽也不重新开始。
7. 核验平台提交时间、批阅状态、分数、错题/未答数及目录完成标记。没有读到结果就记录“已点击确认交卷，结果未核验”。可重复作业只在授权允许且确有错误时根据反馈修正；用户设定的试运行和批量授权门槛应保留。
   本平台成绩提交与课程课时进度分离。常规步骤：在原任务show页的活动iframe内正常开始、填写、提交，保留平台父子页完成通知；核验批阅结果后读取服务器目录，确认本课时完成。不要把答题页导航到独立顶层窗口，返回结果页或只等60秒未必补回丢失通知。
   若目录仍未完成，先核验真实批阅结果满足平台完成条件；已获用户明确授权恢复通知时，可使用scripts/unipus-completion-notification.js补发平台原有完成通知，再读取目录核验。当前适配器仅针对8021已批阅全对的单元作业和100分通过的单元测验，核对任务ID、AI分工、网页版本，排除期末考；其他结果不自动补发。已完成的不补发，每项只进行一次恢复，失败记异常；不重新提交单次试卷、不改答案分数、不直接调用进度接口。未有恢复授权时一次解释并征求授权；本步骤必须纳入最终状态核验。

## 控制 token 与清理

默认返回紧凑 JSON：题目/字段身份、必要材料、当前规则、实际答案或结果摘要。排除 script/style、隐藏字段、CSRF、Cookie、广告和重复说明。结果页只返回分数、状态、未答数和错题；发现截断必须补读缺失部分。

把可重复导航、字段校验和播放监测写进本地代码。AI 只承担解答与判断；固定机械操作由脚本执行。用一个简短状态文件保留进度、结果链接、异常和下一步，不重复输出题库或整页 HTML。不要声称经过量化证明是“最快/最省 token”。

核验完成后按用户清理要求删除题目、答案、快照和测试临时文件。清理前确认路径在指定工作目录中、无活动浏览器占用所需配置。分享技能时只打包技能资源，不包含登录配置、身份、答案、Cookie 或学生号。
