# UMOOCs《英语语法与写作》课程助手 · Agent Skill

把一次网课操作经验整理成可复用的智能体技能：检查课程目录和尝试规则、真实视频连续播放、按授权解答与复核、填写后读回、提交后核验结果。

**使用目标：安装一次 → 亲自登录 → 一次明确授权 → 智能体持续完成范围内任务。** 日常定位、脚本适配、解题、填入和结果检查由智能体承担，尽量不要求你截图或复制网页源码。

技能包含工作方法与浏览器辅助代码。使用它的智能体需要具备浏览器操作、文件读写及持续执行能力；普通纯文本聊天不能直接控制你的课程。登录验证码、平台弹题、规则缺失或工具权限限制可能需要人工处理。

## 最简单的使用方法

### 开始前：先把课程加入“我的课程”

建议先亲自在 UMOOCs 平台登录，搜索并打开《英语语法与写作》，按平台页面提示加入课程，确认它已出现在“我的课程”中，再继续下面的安装和启动步骤。把你实际加入的课程链接交给智能体；不同开课轮次的课程ID可能不同，不必强行使用示例中的8021。

### 1. 把这段话发给你的智能体：安装

```text
请从 https://github.com/Howltan-Neo/unipus-course-assistant 安装
skills/unipus-course-assistant 这个技能。
使用你所在环境的技能安装功能，读取 SKILL.md 及必要参考文件。
检查你是否具备浏览器操作和文件读写能力；有条件时使用允许的 DOM 工具，
否则使用正常界面操作。请自行完成安装和环境检查，告诉我如何启动。
```

Codex 可使用内置 `$skill-installer` 安装指定 GitHub 技能目录。安装后未显示技能时重启应用。手动放置目录和自动发现规则见 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。

### 2. 把这段话发给智能体：启动与授权

把课程链接替换成你的课程。授权清单中不想交给智能体的类型请删掉。

```text
使用 $unipus-course-assistant 处理我的课程：
https://moocs.unipus.cn/my/course/8021

授权范围：视频、可重复普通作业、单元测验、期末考。
我授权你开始并提交上述测验和考试：先核对尝试规则，完整解答、重新复核、
填入后读回检查，再正常交卷；只有一次机会的项目仅提交一次。
尝试规则无法查明的项目先跳过并汇总，不消耗未知机会。

普通作业先试运行一份并核验实际结果，成功后我预先授权继续全部普通作业；
可按批阅反馈修正有错的可重试作业，最多重试两次，仍有错则记录并继续其他任务。
跳过已完成项目，不重做已提交的单次测试。

视频允许真实倍速，采用已验证且能被服务器记为完成的速度，
自然结束并确认完成后自动切换；不伪造记录、不绕过学习要求。
视频运行稳定后交给脚本，不持续花费模型额度监测。

尽量自主完成环境配置、网页检查、定位、适配和调试，不重复询问已有授权。
需要登录时打开页面让我亲自验证；只在必须人工处理的异常时提醒。
保留简短进度记录，任务结束清理题目、答案和临时快照，并汇总完成与异常项目。
```

### 3. 登录，然后保持运行

在智能体打开的课程浏览器里亲自登录，回复“已登录”。不要把密码或验证码发到聊天里。

保持电脑唤醒、网络连通及播放浏览器打开；答题期间保持智能体任务运行。**安装技能不会自动建立全天候后台服务。** 智能体停止后，已安装的视频脚本可以在浏览器里继续运行；新的解题工作需要智能体仍在执行。

需要续接时发：

```text
使用 $unipus-course-assistant，读取上次进度并核对课程实时状态，
继续此前已授权的未完成任务，跳过已完成项目。
```

## 手动安装（没有自动安装器时）

1. 点击本仓库 **Code → Download ZIP** 并解压。
2. 找到 `skills/unipus-course-assistant`，复制整个文件夹到智能体的技能目录。
3. 重新打开智能体，使用上面的启动指令。

Codex 当前官方用户级发现目录为 `~/.agents/skills/`，Windows 对应 `%USERPROFILE%\.agents\skills\`；安装器可能采用该版本配置的技能目录，以实际发现为准。不要同时安装两份同名技能。

其他支持 Agent Skills 的智能体请使用其技能目录。没有技能发现功能但能操作浏览器的智能体，可以直接让它读取本仓库的 [SKILL.md](skills/unipus-course-assistant/SKILL.md) 及链接资源。未逐一验证所有第三方产品。

## 视频脚本如何使用

智能体优先自行配置真实播放控制；需要手动安装 Tampermonkey 脚本时：

1. 在装有 Tampermonkey 的浏览器打开 [《英语语法与写作》视频脚本](skills/unipus-course-assistant/assets/unipus-8021-video.user.js)，点击 **Raw**；浏览器未弹出安装时，在 Tampermonkey 中“添加新脚本”，复制完整内容并保存。
2. 打开《英语语法与写作》课程，右下角出现“视频助手”；可暂停串播。

面板提供1×、4×、8×、16×选择框，可立即调整当前视频速度，并记住下一节的选择。“暂停串播”按钮采用黄底深色加粗文字；暂停串播不等于暂停当前播放器。默认静音，优先选择播放器可用的最低清晰度；本课程实测菜单为高清、标清、自动，因此优先标清。

脚本1.4.1默认选择“末尾三秒”：等待视频元数据加载后，将真实播放器定位到结束前三秒，以1×自然播完；仅在服务器目录确认完成后进入下一节。选择“完整播放”可恢复1×/4×/8×/16×整节播放。跳转失败或未获完成确认时实际16×从头完整播放；若仍未确认，再以1×重播，仍不确认则停留提示；跳过已完成视频，不进入作业或考试。默认静音和最低可用清晰度。**只适配《英语语法与写作》（课程ID：8021）；其他课程由智能体重新核对后适配。**

已观察的视频完成条件是“学习到最后”，播放器界面禁止向前拖动并禁用进度条。另一个账号的多节实测中，修改真实video.currentTime到末尾后自然结束，目录仍记录完成；这是当前课程的实测行为，不等于完整观看，也不能证明其他课程或今后的规则相同。脚本不发送伪造的学习记录，不修改完成状态；以服务器目录为准。8×/16×整节播放也已验证。

### 最新实现逻辑（1.4.1）

1. 读取当前账号的课程目录，核对45个视频的类型、链接和状态，跳过已完成项。
2. 默认**静音**；通过播放器原生清晰度菜单选择**最低可用画质**，本课程为标清，减少打扰和网络占用。
3. 默认“末尾三秒”：等待元数据与视频就绪，每节最多设置一次真实播放位置；末尾以1×自然播放至结束。
4. 跳转报错时立即从头以**16×完整播放**。视频结束后最多等待目录确认120秒；未确认也切换到16×完整播放。
5. 16×完整播放仍未确认时再从头1×重播；仍不确认则显示提示并停止推进。只有服务器目录显示完成才进入下一节。
6. 面板可选择“完整播放”、1×/4×/8×/16×，并记住选择。“暂停串播”停止自动推进，当前视频可以继续播放；“继续串播”重新加载并续接。

遇到播放阻止、缓冲超时或人工交互会在面板提示。视频全部完成后停止导航；脚本不会进入作业或测试。安装一次后，保持浏览器打开即可由脚本继续处理视频，无需智能体持续轮询。

## 为什么能减少操作与额度消耗

- 复用一个登录会话，目录与规则集中读取。
- 提取必要材料和字段，避免反复输出整页源码。
- AI解答后重新验证，按稳定题目ID填入并读回。
- 视频监测和重复机械操作交给代码，模型集中处理判断与异常。
- 单次测验与期末考遵循同一流程：规则核对 → 解答 → 复核 → 填入读回 → 一次提交 → 结果核验。

不保证满分，也没有“最快/最省token”的量化对照。材料、平台规则、模型能力和浏览器工具都会影响结果。
